# Atajos de teclado de MyWhoosh (julio 2025)

Fuente: https://mywhooshinfo.com/blog/mywhoosh-keyboard-shortcuts

## Cambio de marcha virtual

| Tecla | Acción |
|---|---|
| `I` | Subir marcha |
| `K` | Bajar marcha |

> Violeta mapea los botones + y − del mando a estas teclas por defecto.

## Dirección / posición en el pelotón

| Tecla | Acción |
|---|---|
| `←` | Girar izquierda |
| `→` | Girar derecha |
| `A` | Girar izquierda |
| `D` | Girar derecha |

## Emotes y reacciones (fila numérica, no teclado numérico)

| Tecla | Emote |
|---|---|
| `1` | Peace |
| `2` | Wave |
| `3` | Fist bump |
| `4` | Dab |
| `5` | Elbow flick |
| `6` | Toast |
| `7` | Thumbs up |

## UI y modo pantalla

| Tecla | Acción |
|---|---|
| `U` | Alternar UI mínima |
| `H` | Ocultar todos los controles (solo versión HD) |
| `F11` (Windows) | Pantalla completa / ventana |
| `Ctrl+Cmd+F` (Mac) | Pantalla completa / ventana |

## Mapa completo

| Categoría | Tecla(s) | Función |
|---|---|---|
| Dirección | `← →` | Izquierda / Derecha |
| Emotes | `1` – `7` | Animaciones sociales |
| UI | `U` | Modo UI mínima |
| Marcha virtual | `I` / `K` | Subir / Bajar |
| Pantalla | `F11` / `Ctrl+Cmd+F` | Ventana completa |
